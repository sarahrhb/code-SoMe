About this board

What is it?

A shared space for creators in the CODE incubator. You can ask other members for help with editing, filming, design, copywriting or feedback.

How it works

  1. Look at the open requests.
  2. Post your own request and say what you need.
  3. Change the status to "In progress" or "Done" when things move on.

Please note

This is a student project, not an official CODE service. Everyone can read requests. Posting, editing, and deleting need one shared board password. It is not a personal account, so only use fictional names and do not post private information.
